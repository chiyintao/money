## P0：先修决策与成交契约

1. app/strategy/live_models.py:686 的 round_trip_cost_pct 对限价入场返回 2*maker_fee_rate = 4bp。实际 PaperAccount.close 收 taker 4bp 并应用单边滑点2bp，加 maker 入场2bp，约8bp（精确金额随出场名义价值变化，资金费另算）。市场入场仍约12bp。应按入场/退出角色分别计费，供信号门槛、计划、逐品种评分和离线回放共用。不能把限价入场当成限价退出。
2. app/trading/risk.py:292 对净 edge_bps 取 abs，-10bp 和 +10bp 都得到0.4风险倍率。已调用实际 RiskEngine.edge_scale 复现。应保留净边际符号；有效负边际不能产生正仓位，覆盖多空和概率输入并存情形。禁用缩放的兼容语义需要单独明确。
3. .env 当前明确是为了演示而放宽：MODEL_MIN_EDGE_BPS=-1.5、MIN_EDGE_MULTIPLE=0.9、SYMBOL_EDGE_ENABLED=0、SYMBOL_EDGE_MIN_NET_BPS=-999、MODEL_OOD_POLICY=warn。建议把演示配置和绩效验证配置分开；验证配置要求正净边际、启用品种证据门禁，缺数据或无优势时保留影子观测。当前运行会话风险是数据库 aggressive，而.env为balanced；改文件不等于改当前会话，配置版本必须写入每次会话。

## P1：退出与训练可比性

4. 入场价止损不等于净保本：三场共6笔 stop_loss 恰好把 stop 放在 entry，净损益全为负，合计约-8.61063。退出价应按剩余仓位的入场手续费、预估退出手续费、滑点和资金费求净保本价。不可保证跳空时保本，也不可简单把全部止损放宽；需回放比较保本触发点、追踪距离与回撤。
5. 最新训练日志记录 walk-forward 1434 active、净边际-10.33bp、P(edge>0)=0.22；组合回放620笔、净收益-17.01%、最大回撤17.59%，该轮未晋级。CatBoost manifest 中的 walk_forward.backend 为 lightgbm；不能把另一后端的结果解释为该候选的独立验证。每个后端及最终集成都应独立 walk-forward、组合回放，晋级绑定模型哈希、特征、成本、退出策略和配置。
6. 数据已使用 triple_barrier（样本有 barrier/entry_time/label_end_time），不要重复提出“加三重障碍”当新功能。需要进一步对齐线上 scalp 与标签退出策略，并验证方向相关障碍、时间止损和净收益目标的一致性。
7. 主流训练集 profile 为1,263,576行；4个flow字段和3个liquidation字段的 bounds/extremes 均为零。历史训练没有这些信息，线上突然变化不能视为已学会。数据存储有derivatives与derivatives_detail，不应笼统声称没有衍生品数据；flow查询时仅5053行、时间从1789239960000到1789313280000，远短于训练年窗。训练报告要区分真实测量、默认填充、缺失、常量；按可用历史做特征消融，足够数据后再启用新特征。

## 实施与验收顺序

第一轮：统一实际费用并修负edge仓位。以实际账户往返成交账本对照门槛，用负/零/正边际、多空方向验证仓位。
第二轮：净保本与退出策略对照回放，记录每笔MFE/MAE、退出前最大浮盈、费用占名义金额和持仓时长；避免凭40笔成交优化几十个阈值。
第三轮：固定时间分割、purge与embargo，逐后端和集成独立评估；用真实有覆盖的价格/成交/OI/资金费特征建立基线，再逐组加特征。按扣费后组合收益、回撤、独立有效样本和多时间窗口稳定性选择模型，不按训练准确率或单次最优收益。最后留出未参与调参的时间段。
第四轮：同一资金、风险、退出、成本、品种宇宙的小仓影子/模拟对照；全部交易落盘信号时间、模型hash、配置hash、预测毛收益、各项成本、净边际、拒绝原因。收益率不同资金场次不直接累加。
