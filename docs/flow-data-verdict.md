### 关键事实：强平流已经是全市场的

`app/market/websocket_feed.py:59`：

```python
streams.append('!forceOrder@arr')
```

`!forceOrder@arr` 是**一条订阅覆盖所有币种**，不是每币一条。

symbol, and it is the only source of forced-order flow."*

## 我的建议

### 不要现在转波动率

转波动率是"放弃方向预测"的决定。但现在有具体理由相信方向可预测，只是样本不够：

1. **强平是机械性的** —— 它不是情绪，是保证金追缴，有可预测的后续（被动平仓 → 价格冲击 → 回归）
2. **32 小时就追平了 26 个成熟特征** —— 数据量增加应该让信号变强，不是变弱
3. **采集已经在跑** —— 等待的边际成本是 0

### 具体行动

**立刻（今天）**
- 保持采集运行，**不要动它**
- 把 flow 采集扩展到全部交易币种（当前 12 个），因为 62 个币种里 50 个连成交流都没有

**6.5 天后（7 天数据）**
- 重跑本文档的检验。判据：
  - 合并 corr 是否 > 0.02 且 n > 100,000
  - 分样本两半是否**都**超过噪声下限
  - 符号一致性是否改善（目标：≥9/12 同号）
- 若三条都过 → 用 flow 特征重训，这才是有意义的一步

**30 天后（30 天数据）**
- 若信号站稳 → 重训并重新评估晋级
- 若仍不站稳 → **那时**才考虑转向波动率/执行优化

### 关于执行优化（独立的好机会）

这条**现在就可以做，且不依赖任何方向预测**：

- 往返成本 8–12bp，而 134 笔交易手续费 172.28 = 毛收益的 29%
- 48 笔交易的 |毛收益| < 手续费
- 降低执行成本是**确定性收益**，不需要预测对方向

这不是替代方案，是可以并行的独立改善。
