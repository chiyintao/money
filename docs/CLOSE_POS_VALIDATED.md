# close_pos 通过闸门：第一个站得住的候选信号

日期：2026-09-14
结论：**把历史从 894 天扩到 2154 天（2.4 倍）后，`close_pos` 通过了全部闸门。**
这是本项目第一个在多窗口下稳定成立的候选。

**但它还不是"可以下注"** —— 见文末限制。

## 一、为什么能扩到 2154 天

原来的面板被 `ENAUSDT`（2024-04 才上市）卡在 894 天。数据库里其实有 **11 个币
从 2020 年就有完整 5 分钟历史**：

```
BTCUSDT 2020-01-01   ETHUSDT 2020-01-01   XRPUSDT 2020-01-06
LINKUSDT 2020-01-17  ADAUSDT 2020-01-31   ZECUSDT 2020-02-05
BNBUSDT 2020-02-10   DOGEUSDT 2020-07-10  UNIUSDT 2020-09-18
SOLUSDT 2020-09-14   NEARUSDT 2020-10-15
```

用这 11 个币重建面板：**2154 天全截面完整**（原来 894 天，**2.4 倍**）。

```bash
python -m app.models.daily_panel --output data/research_v4/panel_extended.jsonl \
  --symbols ADAUSDT,BNBUSDT,BTCUSDT,DOGEUSDT,ETHUSDT,LINKUSDT,NEARUSDT,SOLUSDT,UNIUSDT,XRPUSDT,ZECUSDT
```

注意：衍生品/资金费/流量数据只回溯到 2025-09，所以扩展面板只能用**价格类特征**。
这正好够检验 `close_pos`。

## 二、894 天 vs 2154 天：t 的形状完全不同

这是本次最关键的一张表——**t 随窗口长度的变化**：

| 窗口 | 894 天面板 | **2154 天面板** |
|---|---|---|
| 120 天 | 1.76 | **2.21** |
| 240 天 | 1.19 | **2.31** |
| 365 天 | — | **2.40** |
| 600 天 | 1.03 | **2.36** |
| 900 天 | — | **2.36** |
| 全期 | 2.07 | **2.43** |

**894 天时 t 在 1.0 附近平台化，只在最后跳到 2.07**（前 600 天只有 1.03）。
**2154 天时 t 从 120 天窗口起就稳定在 2.2–2.4。**

这正是"真实的边缘"与"池化假象"的区别。原来的诊断结论——**这是功效不足，
不是边缘不存在**——被证实了。

## 三、压力测试

| 检验 | 结果 |
|---|---|
| 逐 365 天窗口 | **5/5 为正**，中位 t=1.27 |
| 两半 | +12.61 / +7.58 bps，**都为正** |
| 含 ZEC | +10.68 bps **t=2.45**（也成立） |
| 去 ZEC | +10.09 bps **t=2.43** |
| 留一法（10 次） | **9/10 保持 t≥2**（最差 t=1.81） |
| 零假设对照（3 次打乱） | t = 0.89 / −1.41 / −0.69 |

对比动量信号：留一法时 t 从 3.19 **塌到 1.60**；这里最差只到 1.81，且**含 ZEC 时更强**。
**这不是单币造成的。**

## 四、尾部行为是反的

通常尾部依赖是坏事，这里相反：

| | 平均 | 标准差 | t |
|---|---|---|---|
| 不截断 | +11.58 bps | 0.03594 | 1.50 |
| **±10% 截断** | **+10.09 bps** | **0.01928** | **2.43** |

**均值保留 87%，标准差只保留 54%。** 说明极端日是**围绕一个小而稳定边缘的噪声**，
不是边缘的来源。这与动量信号完全相反（动量截断后只剩 13%）。

因为截断**提高**了 t，闸门的判定顺序必须反过来——要求"原始 t≥2"会错误地拒绝它。
`scripts/extended_gate.py` 里明确记录了这一点。

## 五、经济性

| 项目 | 数值 |
|---|---|
| 日换手 | 19.7% |
| 毛利 | +10.09 bps/天 |
| 成本（4 bps/边） | 1.57 bps |
| **净** | **+8.52 bps/天** |
| 年化（4bps/边） | **约 31%**（对总敞口） |

复利全期（**不含费用**）：净值 **5.89x**，CAGR **+35.1%**，**最大回撤 −43.0%**。

## 六、必须说清楚的限制

1. **最大回撤 −43%。** 这是扣费前、按每日全额敞口复利的结果。实盘要按仓位缩放，
   但 43% 的回撤说明**这不是一条平滑的曲线**，需要真实的仓位管理。
2. **11 个币里有 3 个（ADA/DOGE/BTC）单独移除会让 t 掉到 2 以下**（最差 1.81）。
   不是单币依赖，但**宽度仍然有限**——11 个币的截面很窄。
3. **只有价格数据。** 资金费、持仓量、流量这些更可能携带信息的特征**没有长历史**，
   无法在这个面板上检验。
4. **2154 天仍然只覆盖 2020–2026 一轮周期**（含 2021 牛、2022 熊、2023–24 复苏）。
   没有跨更多宏观 regime 的证据。
5. **未做容量分析。** 11 个主流币流动性充足，但没算过冲击成本。
6. **`close_pos` 的经济含义尚未解释清楚。** 它是"收盘价在当日区间的位置"，
   做多高分位等于买当日强势。这在日频上通常被解释为短期反转/流动性提供，
   但**我没有验证这个机制**，只是知道它不是动量的代理（与 `ret_14d` 相关仅 0.113）。

## 七、下一步

按优先级：

1. **补长历史的基本面数据**（资金费、持仓量）——如果能从归档拉到 2020，
   就能检验更有信息量的特征族。
2. **容量与冲击成本分析**——决定可投入的资金规模。
3. **跨市场稳健性**——在非加密市场或更多币种上复现。
4. **机制验证**——若无法解释为什么有效，就应当按"可能是数据挖掘"对待，
   用前向纸面跟踪而不是实盘来继续验证。

**在 2 和 4 完成之前，这个信号不应投入真钱。**
